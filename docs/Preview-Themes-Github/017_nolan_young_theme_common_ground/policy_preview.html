01 / About this site

Common Ground is an imagined architecture practice created for a static website portfolio. Its projects are fictional design studies. There is no operating studio or client service behind this sample, and the displayed email address uses the reserved example.test domain.

This note describes the sample itself, as of 3 October 2026.

02 / Information in the form

The inquiry form is a demonstration. Its script checks the required fields in your browser and displays a confirmation on the same page. It does not send an email, contact a server, or save the contents to a database or browser storage.

Use invented details. Text stays in the visible fields until you change it or leave the page; your browser may restore form values when returning through its history. The confirmation means only that the demonstration fields were completed, not that a studio received an inquiry.

03 / Cookies and browser storage

The sample code does not set cookies, use local storage or session storage, or include analytics, advertising, tracking pixels, embedded maps, or third-party fonts. The navigation and FAQs do not create a stored preference.

04 / Hosting and requests

Pages, styles, scripts, and photographs load from the same site. No external submission service is connected. If this sample is served by a hosting provider or displayed inside a gallery, that service may receive ordinary request information such as an IP address, requested file, and browser details. Its own policies govern that processing; this sample does not control hosting logs or the surrounding gallery.

05 / Photography and project descriptions

The architectural photographs are illustrative stock by Pierre Châtel-Innocenti and Annie Spratt, supplied locally under the Unsplash License. They are not photographs of Common Ground projects and do not imply a relationship between the photographers, the buildings shown, and this fictional practice.

06 / Questions about the sample

The example contact address is not monitored. For questions about where this sample is hosted or how the surrounding gallery handles data, contact the operator of that gallery through their own website.
