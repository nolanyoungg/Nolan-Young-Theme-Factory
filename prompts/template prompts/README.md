# Template Prompts

This folder stores reusable creative-brief starters.

Copy a template into `prompts/pending/`, rename it for the new business concept, then edit it before running generation.

Templates must describe only the website concept:

- business type
- audience
- services or products
- page content
- visual direction
- tone
- artwork direction
- interaction expectations
- accessibility expectations
- conversion goals

Templates must not mention repository paths, workflow modes, validation, packaging, command-line tools, generated slugs, CI checks, or implementation files.
