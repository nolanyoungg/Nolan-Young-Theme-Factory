# Ridge & River accessibility notes

- A skip link leads directly to each page's main content.
- The mobile navigation button exposes aria-expanded and aria-controls. Escape closes the menu and returns focus to the button. The inline drawer follows normal document tab order.
- Without JavaScript, the navigation remains a readable list and every section stays visible.
- FAQ entries use native details and summary elements.
- Visible focus outlines use the rust or parchment palette against contrasting surfaces.
- Motion is a small entrance translation. Reduced-motion preferences suppress animations and smooth scrolling.
- Inquiry controls have visible labels, browser validation and a live status message. The demo never claims delivery or booking.
- The landscape photograph has a meaningful alternative and an explicit stock credit. Decorative marks have empty alternatives.
- Mobile styles stack the footer, constrain the hero and wrap contact links and long text.

These are implementation notes, not a certification or a claim of a completed accessibility audit. Evaluate keyboard operation, zoom and screen-reader behavior in the deployed WordPress environment.
