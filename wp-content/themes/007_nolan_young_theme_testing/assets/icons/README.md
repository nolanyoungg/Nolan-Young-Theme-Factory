# Icons

This directory contains local icon assets used throughout the Northstar Codeworks theme. These icons are integral to the visual design, ensuring a consistent and polished look across all pages.

## Icon Usage

Icons are primarily used in navigation menus, buttons, and decorative elements. Each icon is carefully selected to align with the company's brand identity and modern software consultancy aesthetic.

## Icon Management

All icons within this directory should be local assets to maintain control over image quality and ensure compatibility across different environments. Avoid using remote images or external libraries to prevent potential loading issues or security vulnerabilities.
