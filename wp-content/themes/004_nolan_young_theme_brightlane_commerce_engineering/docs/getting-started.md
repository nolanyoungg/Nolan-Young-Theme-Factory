# Getting Started

Install the theme in WordPress, activate it, then create pages for Home, About, Services, Work, Blog, Contact, and Privacy Policy. Assign the included page templates where appropriate and set Home as the static front page so WordPress renders `front-page.php`.

Run `npm install` when dependencies are not present, then use `npm run build` to regenerate `assets/css/bundle.css` and `assets/js/bundle.js`.

Configure the Primary and Footer menus with real destinations, review the header panel links, set a custom logo if needed, and publish only policy text that has been supplied or reviewed outside the theme.
