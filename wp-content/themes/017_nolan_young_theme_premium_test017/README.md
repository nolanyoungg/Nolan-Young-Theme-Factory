# 017_nolan_young_theme_premium_test017

This is a premium WordPress theme designed for modern service-based businesses, specifically tailored for website development companies. The theme follows a clean, professional design with a strong emphasis on readability and usability.

## Features
- **Responsive Header**: A sticky header that adapts to different screen sizes, including mobile.
- **Navigation Dropdowns**: Clickable navigation items that expand to show more detailed content.
- **Footer Sections**: Comprehensive footer with links to services, company information, blog posts, contact details, and legal pages.

## Color System
The theme uses a consistent color palette:
- Main background: `#ffffff`
- Secondary background: `#f4f7fb`
- Dark background: `#101827`
- Primary brand: `#2563eb`
- Secondary brand: `#14b8a6`
- Accent: `#f97316`
- Primary text: `#111827`
- Muted text: `#64748b`
- Border and divider: `#e2e8f0`

## Typography
- **Headings**: Clean, editorial style with strong scale.
- **Body Text**: Highly readable sans-serif font.

## Installation
1. Upload the theme folder to your WordPress installation at `/wp-content/themes/`.
2. Activate the theme from the WordPress admin dashboard.
3. Customize using the WordPress Customizer if needed.
