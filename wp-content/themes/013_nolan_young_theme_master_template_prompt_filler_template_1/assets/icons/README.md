# Icons

This directory contains local SVG icons used throughout the theme. Each icon is carefully designed to maintain a clean and professional appearance, supporting the overall visual identity of `Northstar Websites`. These icons are integral to the user interface, enhancing navigation, interactive elements, and information architecture.

## Icon Usage

- **Header Elements**: Icons support the primary navigation (Services, About, Blog) and mobile menu interactions. They ensure clear visual indicators for dropdown triggers and other interactive controls.
- **Footer Links**: Social media icons and other external links use local SVGs to maintain a cohesive brand identity without relying on external resources.
- **Interactive Elements**: Buttons, CTAs, and form fields utilize icons to provide intuitive user experiences, reducing reliance on text alone where appropriate.

## Icon Conventions

- **File Naming**: Each icon file is named descriptively to reflect its purpose within the theme. For example, `icon-services.svg`, `icon-contact-us.svg`.
- **SVG Structure**: Icons are optimized for web performance with minimal external dependencies. They use inline styles where necessary and are structured for easy customization via CSS or SCSS variables.

## Icon Sources

- **Design Assets**: All icons are created by the design team to ensure they align with the `Northstar Websites` brand guidelines. Third-party icon libraries are not used to prevent copyright issues and maintain full control over branding elements.

## Maintaining Icons

To update or replace icons, follow these best practices:
- **Version Control**: Ensure that any changes to SVG files are tracked in version control (e.g., Git). This helps in maintaining consistency across theme versions.
- **Accessibility**: Always ensure that replaced icons maintain accessible attributes such as `aria-label` for screen readers where necessary.
- **Theme Integration**: Test icon replacements thoroughly to ensure they integrate seamlessly with the theme's design and functionality.
