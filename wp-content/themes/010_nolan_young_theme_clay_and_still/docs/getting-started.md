# Getting started with Clay & Still

Activate the prepared theme in WordPress, then create the standard pages listed in README.md. Use Services as the parent of the Featured page. Set a Home page as the static front page if desired; front-page.php supplies the complete sample homepage.

The page-slug files select their named layouts without additional routing. Use the editor's template selector when using different slugs, and update the fixed navigation links to match.

Compile the source with `npm run build`. The theme loads only its local CSS and JavaScript bundles. No third-party fonts or scripts are needed.

This is a fictional ceramics studio. Inquiry controls are intentionally local demonstrations with no persistence or message delivery. No live store, availability, workshop booking or address is provided.
