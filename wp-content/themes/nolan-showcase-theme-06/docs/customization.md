# Customization

- Open the WordPress Customizer to update the hero brand name, headline, description, and call-to-action labels.
- Replace the SVG assets in `assets/images/` with product diagrams, interface illustrations, or branded visuals.
- Add posts to the Journal and optionally create custom post types for services, case studies, and testimonials.
- Keep the dark technical palette unless the brand requires a different tonal direction.
