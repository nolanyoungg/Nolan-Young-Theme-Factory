# Customizing Ridge & River

Palette tokens live in src/scss/abstracts/_variables.scss and theme.json. Layouts use system sans-serif type and compact monospace labels. The main stylesheet imports only the modules used by this design.

Edit sample walk data in inc/helpers.php; detailed page copy lives in page-templates and template-parts. The header and footer use the canonical WordPress page paths. Preserve the ordinary same-frame links.

The stock mountain photograph is the only approved photography. Keep its footer credit and provenance manifest. Local SVG marks are small interface decorations, not landscape substitutes.

The inquiry form intentionally has no delivery or storage handler. A real inquiry service would need a separately configured plugin, accurate privacy information and clear consent behavior. Do not change the demonstration message to imply delivery.

Run npm run build after changing source styles or interactions.
