# Getting started with Clay & Still

Activate the prepared theme in WordPress. Create Home and select it as the static front page under Settings → Reading.

Create pages with slugs `about`, `services`, `work`, `blog`, `contact`, and `privacy-policy`. Create a page with slug `featured` whose parent is Services, giving it the path `/services/featured/`. Native WordPress page-slug templates select each composition. The equivalent named templates can be assigned in the editor.

The Journal sample page contains the full glaze, care, and handbuilding notes. Navigation is curated in the header, footer, and `inc/helpers.php`; there is no menu configuration or custom routing requirement.

Use the prepared Node dependency installation and run `npm run build`. The production outputs stay inside the theme under `assets/css/` and `assets/js/`. The theme does not require remote fonts, trackers, or runtime libraries.

All business content is fictional. No live contact details, booking slots, or products are implied. The inquiry forms do not submit information. The website environment may have separate WordPress or hosting behaviour; review that independently before adapting this design for a real studio.
