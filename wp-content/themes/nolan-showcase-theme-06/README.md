# Nolan Showcase Theme 06

Nolan Showcase Theme 06 is a premium classic WordPress theme for a strategic web design and development company. It pairs a structured, high-contrast layout with responsive sections, local assets, and a static preview that mirrors the WordPress output.

## Included Experiences
- Home
- About Us
- Services
- Work
- Blog
- Contact
- Policies

## Build

```bash
npm install
npm run build
```

The build writes:
- `assets/css/bundle.css`
- `assets/js/bundle.js`

## Notes
- Uses local assets only.
- Avoids remote fonts, scripts, and images.
- Includes a static preview in `docs/themes/nolan-showcase-theme-06/`.
