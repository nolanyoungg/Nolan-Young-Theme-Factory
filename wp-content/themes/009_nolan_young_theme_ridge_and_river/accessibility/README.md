# Ridge & River accessibility

The header includes a visible-on-focus skip link and native navigation links. On mobile, a real button controls an in-flow disclosure with accurate aria-expanded and aria-controls. Escape closes the menu and returns focus to the toggle; focus leaving the header closes it. The disclosure is non-modal and does not trap focus. A noscript navigation remains available.

FAQs use native details and summary. Inquiry fields have visible labels and native validity checks. Demo feedback is announced through a status region and never claims delivery. No user-entered data is transmitted or persisted.

Motion uses short translations only; content is never initially hidden. Reduced-motion preferences remove transitions and animations. Meaningful landscape alternatives describe the photo; decorative marks have empty alternatives.

Responsive rules explicitly constrain hero type, controls, images and footer columns. Manual browser and assistive-technology verification should accompany deployment; these notes are design intent, not certification.
