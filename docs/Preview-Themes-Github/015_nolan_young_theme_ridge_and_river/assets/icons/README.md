# Ridge & River interface marks

The three prepared local files mark-1.svg, mark-2.svg and mark-3.svg are used for the brand, practical field notes and footer. Their simple geometry is adapted to the pine, parchment and rust palette. They are decorative and rendered with empty image alternatives.

The approved stock landscape is the primary photographic asset. These small SVG marks do not substitute for photography. Provenance remains in assets/images/asset-manifest.json.
