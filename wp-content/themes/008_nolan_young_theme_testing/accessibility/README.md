# Accessibility at Northstar Codeworks

At Northstar Codeworks, we are dedicated to ensuring that our website is accessible to everyone. We follow industry best practices and guidelines such as the Web Content Accessibility Guidelines (WCAG) to make sure our content is usable by people with a wide range of abilities.

Our commitment to accessibility includes:

- **Mobile-first behavior**: Ensuring that our site is optimized for mobile devices, which are used by a significant portion of internet users.
- **Usable mobile navigation**: Providing an intuitive and easy-to-use navigation menu on mobile devices.
- **No horizontal scrolling bugs**: Making sure that the content on our site can be viewed without horizontal scrolling, which can be difficult for some users.
- **Tap targets large enough for mobile**: Ensuring that interactive elements are large enough to be easily tapped on a touchscreen device.
- **Visible focus states**: Indicating when an element has keyboard focus so that users who navigate with assistive technologies can see where they are on the page.
- **Semantic HTML**: Using HTML tags appropriately to convey meaning and structure, which helps screen readers understand our content.
- **Proper heading order**: Ensuring that headings are used in a logical order to create a clear hierarchy of information.
- **Alt text for meaningful images**: Providing alternative text for images so that users who cannot see the image can still understand its content.
- **Good color contrast**: Using sufficient color contrast between text and background colors to ensure readability for all users.
- **Keyboard-accessible dropdowns where practical**: Making sure that dropdown menus can be navigated using a keyboard.
- **Reduced-motion consideration for animations**: Allowing users to control the level of motion on our site through browser settings or custom options.
- **No text hidden behind sticky headers**: Ensuring that important content is not obstructed by fixed-position headers, which can make it difficult for some users to see.
- **No overflowing cards, buttons, menus, or hero visuals**: Making sure that all elements on our site fit within the available space without overflowing, which can cause usability issues.

We continuously strive to improve the accessibility of our website and welcome feedback from our users. If you have any suggestions or encounter any issues while using our site, please let us know so we can address them promptly.
