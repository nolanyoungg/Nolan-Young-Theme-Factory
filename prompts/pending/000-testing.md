# WordPress Theme Generation Prompt — Skeleton Template

Use this as a fill-in creative brief for a generated WordPress website theme. Keep the finished prompt focused on the business, audience, content, design, pages, forms, conversion goals, accessibility expectations, and image direction.

## 1. Business Identity

### Business Name

Northstar Codeworks

### Short Business Description

Northstar Codeworks is a senior software development company that builds custom web applications, internal tools, API integrations, and automation systems for growing service businesses and B2B teams. The company helps founders and operations leaders replace fragile spreadsheets, disconnected SaaS tools, and manual processes with reliable software that is easier to run and scale.

### Industry / Category

Software development company

### Primary Conversion Goal

Book a consultation for a custom software, web application, automation, or integration project.

### Secondary Conversion Goals

- Explore service pages
- Read case studies
- View the development process
- Download or request a project planning guide
- Join a practical software operations newsletter

---

## 2. Brand Voice and Style

### Brand Personality

Technical and precise, premium and polished, calm and trustworthy, with a practical senior-engineer tone.

### Writing Style

Clear, direct, benefit-focused copy. Use confident expert language without sounding corporate or bloated. Headings should be crisp and specific. Support copy should explain outcomes, risk reduction, implementation quality, maintainability, and business value.

### Content Density

Detailed service-page copy with strong conversion sections, realistic project examples, and enough technical specificity to feel credible to founders, operators, and technical buyers.

---

## 3. Visual Design Direction

### Overall Website Style

Modern software consultancy website with clean product-interface details, polished dashboard-inspired visuals, restrained motion, and a premium B2B feel.

### Layout Rhythm

Hero, trust bar, services grid, problem/solution section, process, case studies, testimonials, FAQ, final CTA. Use dashboard cards, metrics, system diagrams, code/interface-inspired panels, and sticky CTAs where appropriate.

### Image Direction

Use local, royalty-free, non-copyright-safe imagery or generated CSS interface graphics. Prefer abstract software dashboards, clean office/team imagery, code review panels, integration diagrams, product mockups, workflow boards, and interface cards. Do not use broken image links. Prefer local assets or generated CSS interface graphics.

## 5. Typography Direction

### Heading Style

Large bold geometric headings with a clean SaaS-style rhythm. Headings should feel confident, precise, and modern.

### Body Text Style

Highly readable modern sans-serif body copy with comfortable line height. Use compact technical copy in dashboard cards and larger explanatory copy in conversion sections.

### Font Rules

Use safe local/system font stacks unless the existing generator configuration includes a permitted font strategy. Do not depend on external Google Fonts unless explicitly allowed for this project.

---

## 6. Header and Navigation

Create a polished responsive header.

### Header Layout

Logo left, nav center, CTA button far right. Keep spacing tight and professional. Use a mobile slide-down menu.

### Header Behavior

Sticky on scroll with a solid background and subtle border. Mobile navigation should be keyboard accessible and easy to tap.

### Header CTA

Button label: Book a Consultation
Button destination: Contact page or contact section

### Main Navigation Items and Dropdowns

- Home
- Services
  - Custom Web Applications
  - Internal Tools
  - API Integrations
  - Automation Systems
- Work
- Process
- Resources
- About
- Contact

Do not create empty dropdowns. Every dropdown item should connect to a real generated page or meaningful section.

---

## 7. Pages to Build

Describe pages by business purpose, not by implementation filename. The generator must determine how to create the proper WordPress templates, page templates, template parts, routes, preview sections, and navigation links.

Each page should feel intentionally designed, not copied with only text swapped.

### Home Page

Purpose: Convert qualified software project leads by showing that Northstar Codeworks can design, build, and maintain serious business software.

Main sections to include:

- Hero with animated product-interface visual, clear positioning, and strong CTA
- Trust bar with metrics, client types, and proof points
- Services preview cards linking to real service pages
- Problem / solution section about replacing manual workflows and disconnected tools
- Process section covering discovery, architecture, build, launch, and support
- Featured work preview with realistic case studies

Primary CTA: Book a Consultation
Secondary CTA: View Case Studies

### About Page

Purpose: Build trust around senior engineering judgment, maintainability, communication, and long-term partnership.

Main sections to include:

- Company philosophy
- Senior technical approach
- What clients can expect
- Values around clarity, reliability, security, and maintainable systems

### Services Overview Page

Purpose: Help visitors understand the core services and choose the right path for their project.

Main sections to include:

- Service category overview
- Comparison of common project types
- Engagement models
- CTA to discuss project fit

### Individual Service Pages

Build individual pages for these services. Each service page must have unique copy, unique layout details, a clear value proposition, deliverables, process, FAQ, and CTA.

- Custom Web Applications
- Internal Tools and Admin Portals
- API Integrations
- Workflow Automation Systems
- Legacy System Modernization
- Technical Discovery and Architecture

### Work / Portfolio Page

Purpose: Show credible software outcomes through realistic case studies and project summaries.

Showcase items to include:

1. Operations dashboard for a multi-location service business
2. Client portal for a professional services firm
3. API integration layer connecting CRM, billing, and scheduling tools
4. Workflow automation system for quote intake and project handoff

Each showcase item should include:

- Project summary
- Client type
- Challenge
- Solution
- Result
- Services used
- Timeline, technical approach, and maintainability notes

### Process Page

Purpose: Explain how Northstar Codeworks reduces project risk and keeps software work clear.

Process steps:

1. Discovery and business workflow mapping
2. Technical architecture and implementation roadmap
3. Interface design and prototype review
4. Iterative build, QA, and stakeholder feedback
5. Launch, documentation, monitoring, and support

### Resources / Blog Page

Purpose: Provide educational content that helps business owners make better software decisions.

Include sample educational resources, guide cards, blog-style article previews, or learning content relevant to the business.

Suggested topics:

- When custom software beats another SaaS subscription
- How to plan an internal tool project
- API integration mistakes that create long-term maintenance problems
- What a technical discovery phase should include

### Contact Page

Purpose: Convert qualified leads into consultation requests with clear expectations and form fields.

Include:

- Contact intro copy
- Contact form design
- Business contact details
- Service interest selector
- Expected response time
- CTA for urgent inquiries
- Trust/support copy

### Optional Additional Pages

Add these only if they fit the business and project scope:

- Pricing / Engagement Models
- Technical Discovery
- Support and Maintenance

## 9. Homepage Section Requirements

The home page should include a complete business-focused flow.

Required sections:

1. Hero section that strongly grabs the user's attention, looks polished, and includes animation in the hero area and as the user scrolls.
2. Trust bar with believable stats, client types, badges, or proof points.
3. Services preview section with cards linking to real service pages.
4. Problem / solution section explaining why the business exists.
5. Process section explaining how working with the business works.
6. Featured work or case-study preview section.
7. Testimonials or review-style proof section.
8. FAQ section.
9. Final CTA section.

---

## 10. Footer Requirements

Create a complete footer with:

- Business name and short summary
- Main navigation links
- Service links
- Resource links
- Contact details
- Social links or inactive social labels if needed
- Newsletter/signup area if appropriate
- Copyright line
- Privacy / Terms links if appropriate

All footer links should point to real generated pages, real sections, or safe non-navigating labels only when unavoidable.

---

## 11. Responsive and Accessibility Requirements

The theme must be responsive and accessible.

Required:

- Mobile-first behavior
- Usable mobile navigation
- No horizontal scrolling bugs
- Tap targets large enough for mobile
- Visible focus states
- Semantic HTML
- Proper heading order
- Alt text for meaningful images
- Good color contrast
- Keyboard-accessible dropdowns where practical
- Reduced-motion consideration for animations
- No text hidden behind sticky headers
- No overflowing cards, buttons, menus, or hero visuals

---

## 12. Quality Bar

The finished theme should feel like a polished finished website, not a starter shell.

Avoid:

- Lorem ipsum
- Empty cards
- Empty nav items
- Broken links
- Duplicate sections with only minor text changes
- Generic "About Us" filler
- Unstyled form fields
- Inconsistent spacing
- Random colors not in the palette
- Remote images that may break
- Overly complex code that does not match the existing style

Include:

- Specific business copy
- Clear page intent
- Realistic service descriptions
- Realistic case studies or portfolio examples
- Strong CTAs
- Responsive polish
- Modern spacing
- Consistent buttons
- Consistent card styles
- Useful footer and navigation
