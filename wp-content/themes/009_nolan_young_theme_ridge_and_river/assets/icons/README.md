# Ridge & River interface marks

mark-1.svg is the ridge-and-river brand mark. mark-2.svg is a compass-inspired wayfinding detail. mark-3.svg is a simple trail marker. These local decorative SVGs use the theme palette, have no external references and are never used as primary photography.

The original seeded asset provenance remains in assets/images/asset-manifest.json. The SVG presentations were personalized for this theme.
