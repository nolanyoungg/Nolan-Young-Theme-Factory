# Getting Started

Install the theme in WordPress, activate it, then create pages for Home, About, Services, Work, Blog, Contact, and Policy content. Assign the homepage to use `front-page.php`, apply the included page templates where appropriate, and configure Primary and Footer menus.

Run `npm install` when dependencies are not present, then use `npm run build` to regenerate `assets/css/bundle.css` and `assets/js/bundle.js`.
