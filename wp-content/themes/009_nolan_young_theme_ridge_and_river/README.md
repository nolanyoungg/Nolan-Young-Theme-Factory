# Ridge & River

A fictional small-group walking outfitter with a pine, parchment and rust field-guide design. The six-part home page introduces walks, difficulty, ethos, packing and inquiry. Route concepts are illustrative and never claim live availability.

## Pages

Create ordinary WordPress Pages with these paths. The matching slug templates select the completed layouts automatically:

- /about/ — Our story
- /services/ — Walk with us
- /services/featured/ — Full-day ridge walk (a child page named featured under services)
- /work/ — Route field notes
- /blog/ — Walking journal
- /contact/ — Trip inquiry
- /privacy-policy/ — Privacy

The front-page template serves /. The same layouts are available as named page templates in the editor. If /blog/ is assigned as the Posts page, home.php displays the sample journal. Standard archives and search display published posts.

## Local build

Run npm run build to compile src/scss/main.scss and src/js/main.js into assets/css/bundle.css and assets/js/bundle.js. Existing development dependencies are retained. No runtime downloads, external fonts, analytics, custom content types or custom routing are installed.

## Demonstration behavior

The inquiry uses local browser validation only; no entry is saved, emailed or booked. Use sample details. The example email address is non-deliverable. WordPress comments are not enabled by the sample page layouts.

## Photography

The approved mountain photo is by Alexander Hipp on Unsplash. Its source, license and attribution are recorded in assets/images/asset-manifest.json and the footer. Different crops use this same photo as an illustrative landscape, never as a completed trip. All three local interface marks appear in the theme.

Prepared package and WordPress identity fields are preserved. No previews, ZIPs or reports are generated by this theme pass.
