# Blocks

This directory contains reusable block templates for the Northstar Codeworks WordPress theme. Each block is designed to enhance the visual and functional elements of the website, ensuring consistency and ease of maintenance.

### Block Overview
- **Hero Section**: Features an animated product-interface visual, clear positioning, and strong CTA buttons.
- **Trust Bar**: Displays metrics, client types, and proof points to build trust with visitors.
- **Services Preview Cards**: Links to detailed service pages, showcasing the range of offerings by Northstar Codeworks.
- **Problem/Solution Section**: Explains why Northstar Codeworks exists and highlights their expertise in replacing manual workflows and disconnected tools.
- **Process Section**: Outlines the steps involved in discovery, architecture, build, launch, and support phases.
- **Featured Work Preview**: Includes realistic case studies to demonstrate credible software outcomes.
- **Testimonials/Reviews**: Features client testimonials to reinforce trust and credibility.
- **FAQ Section**: Answers common questions about services and processes.
- **Final CTA Section**: Encourages visitors to take action, such as booking a consultation or viewing case studies.
