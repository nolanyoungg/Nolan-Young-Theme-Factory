# Common Ground — static website brief

## Business Identity
Common Ground is an independent architecture practice designing modest, enduring homes and thoughtful neighborhood spaces. This is a fictional portfolio sample. Audience: homeowners and small cultural organizations. Primary action: start a project conversation.

## Content Requirements
Write polished, specific copy about renovations, compact new homes, and civic interiors. Use three clearly fictional example projects with locations described generically. No fabricated awards or testimonials. Contact details use example.test; no real business address. Journal has three useful short articles on light, materials and reuse on the journal page itself. Include privacy and one detailed renovation service page.

## Header and Navigation
Brand at left, compact textual desktop navigation and project CTA. On mobile show brand and Menu button with an accessible expandable navigation panel. All nine required pages link consistently. Navigation must work inside the gallery iframe. Use sample-relative links; no external requests.

## Pages to Build
Complete the nine required static HTML files. Index and homepage are equivalent. Home: restrained editorial hero, one large approved architectural photograph, numbered project list, philosophy strip, services, project inquiry CTA. About: studio principles and approach. Services: three coherent offerings and FAQ. Work: three substantial sample projects with distinct layouts and approved images. Journal: three articles with fragment links. Contact: clearly demo inquiry form and local success feedback. Privacy: honest static demo policy. Service detail: renovation scope, process, example and FAQ. No dead-end buttons.

## Visual Design Direction
Warm ivory, forest ink, muted ochre; charcoal text. Editorial serif display headings, compact system sans body. Spacious but purposeful, confident asymmetric desktop layout, thin rules, numbered indexes, elegant restrained motion. Never build a generic SaaS card wall. Keep headlines controlled at 390px and every footer/nav element inside the viewport. Use the approved Form & Field architectural photo catalog supplied by the runner; reinterpret it for this new identity. No new image acquisition during generation.

## Color System
Canvas #f4f1e8, ink #20372f, accent #a66d31, muted #6b726a, white #fffef9. Accessible contrast, visible focus rings. Original CSS geometric flourishes may support photography but must not replace it.

## Functionality
Accessible mobile menu with aria-expanded, Escape and correct keyboard behavior. Native details/summary FAQ. Contact form is demo-only; no network/storage and honest live-region feedback. Reduced-motion support. Progressive enhancement: page navigation/content usable without JS. Avoid UI language about implementation or conversion.

## Supporting Documentation
README lists pages, imagery provenance location, interactions and static limitations. content.json contains a short identity/content plan. Preserve prepared sample.json and every approved image/manifest. No PHP, npm build or WordPress files.
