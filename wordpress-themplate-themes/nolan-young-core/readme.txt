Portable content models, secure forms, privacy tools, and access rules for Nolan Young sites.

== Description ==

This companion plugin keeps durable site behavior independent from the active theme.

== Installation ==

1. Upload and activate the plugin.
2. Use the Services menu to create service content.
3. Place the provided contact or newsletter shortcode on a page.
