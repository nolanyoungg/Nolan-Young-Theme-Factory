# Ridge & River

A fictional small outdoor guiding and walking outfitter. Pine, parchment and rust frame an editorial landscape, numbered trail rows, difficulty notes and practical trip information.

## Pages

Create ordinary WordPress Pages with these slugs. The theme's standard page-slug templates select the corresponding layouts automatically; the named templates can also be assigned in the page editor.

| Destination | Slug | Template |
| --- | --- | --- |
| Home | site root | front-page.php |
| Our story | about | Our Story |
| Walk with us | services | Walk With Us |
| Field notes | work | Route Field Notes |
| Journal | blog | Walking Journal |
| Plan a walk | contact | Trip Inquiry |
| Privacy | privacy-policy | Privacy and Demo Information |
| Full-day ridge walk | featured, child of services | Full-day Ridge Walk |

Use pretty permalinks. Keep Blog as an ordinary Page for the curated sample journal, or assign it as the posts page to use the included home.php layout. Standard post, search, archive and error templates remain available. Page creation belongs to site setup; this theme does not create database content or rewrite routes.

## Build

Run `npm run build` to compile source SCSS and JavaScript to local assets. `npm run dev` runs the existing watch build. No additional dependencies, remote fonts or runtime services are required.

## Content and assets

The sample itineraries do not claim real availability, operated trips, qualifications, awards or reviews. The inquiry controls are a local demonstration: they do not submit, email or store entries.

The only photograph is assets/images/hero/editorial-hero.jpg by Alexander Hipp, used under the Unsplash License as recorded in assets/images/asset-manifest.json. It appears in deliberate crops and is not represented as a real trip destination. Three prepared decorative marks appear in the branding, practical notes and footer. All runtime assets are local.

Prepared theme metadata and package identity are retained. Setup and customization notes are in docs/. No preview, packaging or publication is performed by this theme.
