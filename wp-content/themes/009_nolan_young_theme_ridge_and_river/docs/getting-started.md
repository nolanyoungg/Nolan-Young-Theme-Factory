# Getting started with Ridge & River

Activate the prepared theme in WordPress. Create the ordinary pages listed in README.md with their exact slugs. Make featured a child of services. The slug templates provide sample content without rewriting requests or creating database records. A static front page is optional because front-page.php already supplies the home layout.

Run npm run build after SCSS or JavaScript edits. This command writes only the two local runtime bundles.

Browse each requested page and test navigation with keyboard and touch. The fictional route descriptions are not navigable itineraries. No dates, prices, credentials or real meeting points are asserted.
