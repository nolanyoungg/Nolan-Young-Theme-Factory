# Getting started with Blue Hour

Activate the theme, create the pages listed in README.md, and assign the home page under WordPress Reading settings if using a static front page. Use the exact page slugs so the standard page templates resolve. The Featured page belongs under Services.

Run `npm run build` after source changes. Compiled bundles live in assets/css and assets/js. All runtime resources are local.

This is a fictional demonstration: do not publish the sample dates as real programming. The inquiry form has no server handler, delivery, persistence, payment, or reservation behavior.
