A few things to know.

Which allergens are in the bakes?

All breads contain wheat. Seeded loaves also contain sesame. Honey buns contain wheat, milk and egg; honey butter contains milk. Everything shares a preparation space, so this sample menu cannot promise an allergen-free product.

Can I reserve a loaf?

This sample site does not take reservations. At a real bakery, check availability directly before making a special trip. Fresh loaves are best collected early.

Is sourdough gluten-free?

No. Our sample sourdough uses wheat flour and contains gluten. Slow fermentation does not make it gluten-free.
