# Blue Hour

Business: Blue Hour, an intimate fictional jazz listening room. This is a fictional sample brand with a complete, polished website.

## Visual direction
Midnight navy, electric periwinkle, warm ivory, brass accent. Strong poster typography with oversized condensed-looking system sans lettering, asymmetric gig-poster blocks, instrument close-up photography, thin ticket-stub separators and punchy date badges. Build a memorable dark music venue site, not an agency page.
Opening headline: “Stay for one more set.”
Do not reuse the starter's section order, blue gradients, mega-menu architecture, or giant grid of software services. Compose an intentional distinct design with a modest 4–6 section homepage, consistent inner pages, and a fully branded footer.

## Pages and navigation
Home: poster-like hero with piano photo, sample weekly lineup, listening room story, practical visit notes, private events invitation. About: listening culture and room atmosphere. Services: live sessions, listening nights and private events. Work: performance/program archive with fictional concept event names. Journal: listening notes and jazz introductions. Contact: visit information and booking inquiry. Service detail: listening-room private event with capacity examples clearly labeled illustrative. All event dates and names are demo content, not real ticket availability.
All of these must be complete browseable pages with real sample copy. Navigation routes: Home /, About /about/, Services /services/, Work /work/, Journal /blog/, Contact /contact/, Privacy /privacy-policy/, and Service detail /services/featured/. Use these destinations consistently, relabeling the navigation naturally for this business. Use ordinary same-frame links so visitors can navigate the website inside an embedded preview. Every page must provide a route home and relevant next steps.

## Interaction and accessibility
Use a minimal accessible mobile navigation with an operable hamburger, accurate expanded state, Escape close and visible keyboard focus. All pages must remain readable at 390px without horizontal overflow. Use a subtle CSS transition or intersection reveal with reduced-motion support; essential content must remain visible when JavaScript is disabled. Provide useful FAQ details, readable form labels, a friendly static-demo notice for submission controls, a skip link, and meaningful image alternatives. Forms must not falsely claim a message or payment was sent. No remote fonts, trackers, external runtime scripts, or dependency additions.
