# Icons

This directory contains SVG icon assets used throughout the Northstar Codeworks theme. These icons are designed to enhance the visual appeal and functionality of the website, providing a consistent and modern aesthetic that aligns with the brand's premium B2B feel.

## Icon Usage

- **Navigation:** Icons are used in the header navigation menu for better accessibility and user experience.
- **Services Grid:** Each service card features an icon to represent its specific offering.
- **Call-to-Action Buttons:** Icons accompany buttons to visually guide users through key actions such as booking a consultation or exploring services.
- **Problem/Solution Section:** Icons illustrate the problems Northstar Codeworks solves and the solutions they provide, making complex concepts more digestible.

## Icon Variations

- **Primary Brand Color (#2563eb):** Used for main icons to maintain brand consistency.
- **Secondary Brand Color (#14b8a6):** Utilized for secondary or accent icons where a pop of color is desired, such as successful workflows or connected systems.
- **Neutral Colors:** For icons that need to blend into the background without distracting from the content.

## Icon Naming Convention

Icons are named according to their function or visual representation. This naming convention ensures clarity and makes it easier to manage and update the icon set in the future.

Example: `custom-web-applications.svg`, `internal-tools.svg`

## Maintaining Icons

- **Local Assets:** All icons should be stored locally within this directory to ensure consistent performance and reliability without relying on external sources.
- **Version Control:** Keep icons under version control to track changes and facilitate collaboration among team members.
- **Accessibility Considerations:** Ensure that all icons have descriptive `alt` attributes for screen readers, enhancing accessibility for users with visual impairments.

## Updating Icons

To update or add new icons:
1. Replace the existing SVG file with a new version if needed.
2. Add a new SVG file following the naming convention and ensure it adheres to the theme's color palette and design guidelines.
3. Update any references to these icons in the theme files to reflect the new or updated assets.
