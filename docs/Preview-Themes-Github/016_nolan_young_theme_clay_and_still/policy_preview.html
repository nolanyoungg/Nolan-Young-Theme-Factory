Privacy

A clear note on this demo.

Clay & Still is a fictional sample brand. The following describes the behaviour built into this theme, rather than a policy for an operating ceramics business.

Demo inquiries

The inquiry controls check sample fields in your browser and display a demonstration notice. They do not send an email, store an inquiry, take a payment, or reserve a workshop. Please do not enter personal or sensitive information.

Images & site assets

The theme loads its photographs, styles, and scripts locally. It does not include remote fonts, analytics, advertising trackers, or third-party runtime scripts. Photographer credit links lead to Unsplash when selected.

The website environment

WordPress, the hosting provider, or separately installed plugins may process technical data, logs, cookies, or comments independently of this theme. The site operator must review those services and publish an accurate policy before using this design for a real business.

Before a real studio opens

The operator should provide verified contact details, explain collection and retention of personal information, and replace demonstration forms with a suitable service. This sample contains no active studio contact address.
