# Customization

Edit global colors, spacing, typography, component styles, and page styles in `src/scss/`. Keep `src/scss/main.scss` as the single SCSS entry point and keep compiled outputs named `assets/css/bundle.css` and `assets/js/bundle.js`.

Business copy, service data, blog cards, work cards, and image references are centralized in `inc/helpers.php` where practical. Replace ForgeCart Studio copy only with verified business details. Do not add fabricated certifications, partner badges, client revenue, or guaranteed performance claims.

Seeded stock photos are documented in `assets/images/asset-manifest.json`. Add new licensed images only inside the existing hero, portfolio, or texture folders and update documentation before use.
