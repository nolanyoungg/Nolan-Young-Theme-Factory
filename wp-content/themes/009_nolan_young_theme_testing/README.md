# Northstar Codeworks WordPress Theme

This theme is designed for Northstar Codeworks, a software development company. It follows the creative brief provided to ensure a polished and professional look suitable for a modern B2B consultancy.

## Features
- Responsive design optimized for mobile devices
- Modern and clean UI with dashboard-inspired visuals
- High-contrast color scheme for readability
- Customizable service pages, case studies, and process sections
- Accessible navigation and form elements
- Contact forms integrated with wp-admin form management

## Installation
1. Place this theme folder into the `wp-content/themes/` directory of your WordPress installation.
2. Activate the theme from the WordPress admin dashboard.
3. Customize content through WordPress pages, posts, and widgets as needed.

## Customization
- Edit the CSS files located in `/css/` to customize styles further.
- Modify PHP template files such as `header.php`, `footer.php`, and `front-page.php` for structural changes.
- Update images and logos by replacing existing ones in the `/images/` directory.

## Support
- For any issues or customization needs, contact Northstar Codeworks through the provided contact form on the website.
