# Getting Started

Activate the ForgeCart Studio theme in WordPress, then create Home, About, Services, Work, Blog, Contact, and policy pages. Assign the included page templates where appropriate and set the Home page as the static front page.

Configure the Primary menu for Services, About, Work, and Blog. Configure the Footer menu with real generated destinations only. Add a custom logo if desired; otherwise the local ForgeCart SVG wordmark support appears through the theme helper.

Run `npm install` when dependencies are not present, then use `npm run build` to regenerate `assets/css/bundle.css` and `assets/js/bundle.js`.
