# Set up Ridge & River

1. Activate the prepared theme in WordPress.
2. Create Home and the ordinary Pages listed in README.md. Create Featured with Services as its parent so its URL is /services/featured/.
3. Choose Home as the front page in Settings → Reading.
4. Use the page slugs in the README so the standard page-slug templates load automatically. Each named template is also available in the editor.
5. The Blog page displays the three complete sample journal entries. A posts-page assignment uses home.php with the same field journal.
6. Run `npm run build` after changing SCSS or JavaScript.

The theme intentionally offers fictional sample content. There are no live bookings, payment controls, mail delivery, submission records or custom content types. The inquiry button only checks sample fields and announces that nothing was sent.

Before operating a real outfitter, replace the sample content and connect any required forms through an appropriate plugin. Provide accurate route, business, privacy and meeting information. Keep the photo credit and approved asset provenance intact.
