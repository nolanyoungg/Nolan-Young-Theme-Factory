Before we begin

A few useful
questions.

Every project starts with its own circumstances.

When should I speak to an architect?

As soon as you have a question about a site or an existing building. Early conversations can help define the brief before you commit to a layout, purchase, or construction schedule.

Do I need a finished brief?

No. A few photographs, a rough budget range, and a list of what is and is not working are a useful beginning. We would shape a clearer brief together.

How would fees be agreed?

After an initial discussion, the scope, stages, deliverables, and exclusions would be set out in a written proposal. Specialist advice and statutory fees would be identified separately; this sample does not quote fees.

Can the work happen in stages?

Yes, when the building and scope allow it. We would plan the whole first, then consider sensible phases so that early work does not prevent later improvements.

Are these completed projects?

No. Common Ground and the three portfolio projects are fictional. Photographs are approved architectural references, not images of built work by this practice.
