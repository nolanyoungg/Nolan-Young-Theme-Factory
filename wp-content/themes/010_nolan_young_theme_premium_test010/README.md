# 010_nolan_young_theme_premium_test010

This is a premium WordPress theme designed for modern service-based businesses, specifically tailored for a website development company named Northstar Websites. The theme features a clean and professional design with a strong focus on content and user experience.

## Features
- **Responsive Header**: A sticky header that transitions into a scrolled variant after scrolling.
- **Navigation Panels**: Dropdown panels for Services, About, and Blog sections with detailed content.
- **Homepage Sections**: A polished homepage with 15 sections covering various aspects of the business.
- **Footer**: A full-width footer with clear navigation and contact information.

## Installation
1. Upload the theme folder to your WordPress installation's `wp-content/themes/` directory.
2. Activate the theme from the WordPress admin panel.

## Customization
The theme uses a color system defined in CSS custom properties for consistency across components. You can modify these properties in the `src/scss/_variables.scss` file and recompile the styles if necessary.
