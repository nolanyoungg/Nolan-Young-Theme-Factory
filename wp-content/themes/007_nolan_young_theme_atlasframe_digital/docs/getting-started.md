# Getting Started

Install and activate Atlasframe Digital in WordPress. Create pages for Home, About, Services, Work, Blog, Contact, Policy content, and service-detail destinations. Set Home as the static front page, assign the included templates to supporting pages, configure Primary and Footer menus, and confirm `hello@atlasframe.digital` appears anywhere contact guidance is needed.

Run `npm install` when dependencies are not present. Use `npm run dev` while editing source files and `npm run build` before release so `assets/css/bundle.css` and `assets/js/bundle.js` are current.
